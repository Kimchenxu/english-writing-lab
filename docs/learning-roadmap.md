# 28 天英语写作路线

每天固定六种训练，难点逐渐改变：**搭配 → 造句 → 精修 → 连接 → 段落 → 重写**。Day 01–07 已上线完整题库；以下其余日期为待创建的课程计划，首页不会假装它们已经可练。

## Week 01 · 从词到句（Day 01–07，已上线）

| Day | 核心目标 | 学习重点 |
|---|---|---|
| 01 | Words into sentences | have an impact on、provide feedback、lead to |
| 02 | Precisely simple | 句子完整、限定范围、take into account |
| 03 | Cause and effect | result in/from、due to、be associated with |
| 04 | Contrast and concession | although、despite、whereas、nevertheless |
| 05 | Academic / technical usage | evaluate a model、pose a challenge、latency / throughput |
| 06 | Argumentation | claim、evidence、reasoning、limitation |
| 07 | Integrated challenge | 综合写作 160–210 词，平衡评价两种观点 |

## Week 02 · 从句到段落（Day 08–14，规划）

| Day | 核心目标 | 建议题目 |
|---|---|---|
| 08 | Topic sentence | 如何确定一个段落只表达一个中心思想 |
| 09 | Explanation depth | 为什么“解释机制”比空泛结论重要 |
| 10 | Example precision | 从笼统例子变成可检验的例子 |
| 11 | Paragraph unity | 删除偏离段落中心的句子 |
| 12 | Coherence without templates | 不靠大量 Furthermore / Moreover 组织顺序 |
| 13 | Nuanced claims | may、tend to、be likely to、under certain conditions |
| 14 | Timed paragraph | 15 分钟写作 + 15 分钟精修 |

## Week 03 · 学术与技术语言（Day 15–21，规划）

| Day | 核心目标 | 建议题目 |
|---|---|---|
| 15 | Describe trends | increase、decrease、remain stable、account for |
| 16 | Data interpretation | avoid assuming causation from correlation |
| 17 | Compare results | outperform、underperform、relative to、in contrast to |
| 18 | Scientific register | suggest、indicate、demonstrate、cannot establish |
| 19 | Systems terminology | bottleneck、latency、throughput、scalability、trade-off |
| 20 | Explain a mechanism | input → process → bottleneck → measurable result |
| 21 | Technical paragraph | 写 180–220 词的 ML systems 小型评述 |

## Week 04 · 限时输出与改写（Day 22–28，规划）

| Day | 核心目标 | 建议题目 |
|---|---|---|
| 22 | Plan in 3 minutes | 论点与段落顺序 |
| 23 | Counterargument | 认真处理反方观点 |
| 24 | Avoid wordiness | 删除冗余，提高信息密度 |
| 25 | Connect paragraphs | topic sentence 和 ending link |
| 26 | Diagnose recurring errors | 针对自己 top 5 错误重复练 |
| 27 | Timed integrated writing | 规划、写作、检查、再写 |
| 28 | Pre/post comparison | 对比 Day 1 和 Day 28 的写作样本 |

**训练原则：** 认识高阶词汇，不等于能主动使用它。把“懂但是写不出”当作检索与输出技能的缺口，用可复用搭配和句子结构来缩短差距。
